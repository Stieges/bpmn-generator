Generated by `scripts/bench/layout-metrics.mjs`. Not part of `npm test` — a snapshot for
`docs/layout-quality-analysis.md`, re-run on demand, not enforced as a regression gate.

Columns: crossings (pairwise segment intersections between non-adjacent sequence-flow edges),
bends (total direction changes / edges with <=1 bend), diagonals (non-orthogonal segments —
should be 0), area (bbox px^2, and px^2 per node), chain alignment (plain in/out-degree-1 links
sharing center-y, a simplified proxy — see module doc comment), edge-through-node (segments
crossing a foreign node box).
